# NeuralForensics NSU // Cyber Lab

A futuristic cyber-lab interface for AI / deepfake media analysis. Upload a video or
image, paste a YouTube/social link, or use your live camera, and the system reports
whether the media shows signs of AI generation or manipulation — with telemetry and
a written forensic report generated by the local **Forensic-X Expert** engine.

Everything runs **locally on your machine**. Your media never leaves your computer,
and no API keys or internet are required for analysis once the models are downloaded.

## What it detects

- **Deepfake / AI likelihood** — a dedicated image classifier (`dima806/ai_vs_real`)
  scores sampled frames for synthetic artifacts.
- **Humans & activity** — YOLOv8 tracks people and labels activities (walking,
  running, sitting, standing, using a phone, reading, etc.).
- **Spectral forensics** — Laplacian edge sharpness and FFT spectral attenuation
  back up the classifier.
- **Written AI report** — Forensic-X Expert turns the numeric results into a plain-language
  forensic conclusion.

## How to run it

**Easiest way (macOS):** double-click **`start.command`**. It starts the server and
opens `http://localhost:8080` in your default browser automatically.

**Manually:**

```bash
cd "deepfake 2.0"
python3 detector_server.py
```

Then open **`http://localhost:8080`** in a modern browser (Chrome, Safari, Edge, Firefox).

The first launch downloads the models if they are not already cached, so it can take a
little while. Subsequent launches are fast because the models are cached locally.

> The site is a local web app, not a hosted service. The `http://localhost:8080` URL
> only works while the server process above is running.

## Using the interface

The dashboard is split into three pages, accessed from the menu at the top:

1. **Analyze** — choose one of three sources, then press **Run Analysis**.
   - **Live Camera** — enable your camera and analyze the live frame.
   - **Upload Media** — click or drop an MP4 video or an image.
   - **URL Analysis** — paste a YouTube, TikTok, Instagram, Facebook, X, or direct
     media link.
2. **Results** — the verdict, the synthetic-likelihood score, detected humans and
   their activities, plus the forensic telemetry (Laplacian, FFT) for the analyzed media.
3. **AI Report** — the full written explanation from the Forensic-X Expert engine.

After an analysis finishes, the app moves you to **Results** automatically. Use the
menu to switch between pages at any time.

## Fetching sample media

Download the bundled demos (creates `NSU_Demo_Videos`):

```bash
python3 fetch_test_media.py
```

Any MP4 files in `NSU_Demo_Videos` can be dropped straight onto the **Upload Media**
card for quick tests.

## Project layout

- `detector_server.py` — the local server and analysis pipeline (Forensic-X Expert, YOLOv8,
  AI classifier, spectral forensics, URL fetch via yt-dlp).
- `index.html` / `app.js` / `style.css` — the web interface (three-page, menu-driven).
- `start.command` — one-click launcher for macOS.

## Notes

- Live camera capture is restricted to `localhost` or an HTTPS origin by browsers.
- URL extraction for YouTube uses yt-dlp and depends on YouTube's current behaviour;
  if a link can't be fetched, the app tells you so and you can download and upload
  the file directly instead.
